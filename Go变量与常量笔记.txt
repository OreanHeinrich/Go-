Go 语言学习笔记 —— 变量与常量

fmt.Print：输出到控制台（仅只是输出）
fmt.Println：输出到控制台并换行
fmt.Printf：仅输出格式化的字符串和字符串变量（整型和整型变量不可以）
fmt.Sprintf：格式化并返回一个字符串，不输出。


变量部分
    var 变量名称 数据类型 = 变量值 / var 变量名称 = 变量值
    var 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ... /  ...

    短变量声明 :=
        只能用于函数体内（局部作用域），不能用于包级变量，包级变量必须用 var 声明
        自动类型推断，无需显式指定类型：name := "Go"

        多变量声明
        同时声明多个   a, b := 1, "hello"
        左侧至少有一个新变量时，可对已存在变量重新赋值：a, b := 2, 3,  全部已存在时必须用 = 赋值。
        
    作用域与遮蔽
        作用域为当前块 {},内层同名变量会遮蔽外层，外层值不受影响。

    var：包级/局部均可，可只声明不赋值（零值），可指定类型。
    = ：仅局部，必须立即赋值，类型靠推断。


常量部分
    单个常量声明：const 变量名称 数据类型 = 变量值   /   const 变量名称 = 变量值
    多个常量声明：const 变量名称,变量名称 ... ,数据类型 = 变量值,变量值 ...  /   const 变量名称,变量名称 ... = 变量值,变量值 ...

    Go 语言没有枚举，通常使用常量组来实现枚举,示例：
        const (
            Unknown = 0
            Female  = 1
            Male    = 2
        )

    常量表达式中函数必须是内置函数，如len()...

    iota计数器（只能在 const 中使用）
        iota 是编译期计数器，每个 const 块从 0 开始，每新增一行 +1。
        遇到下一个 const 时重置为 0。

        常量值省略规则
            省略常量值时，默认复用上一行的表达式（含 iota）。
            因 iota 逐行递增，省略行会得到递增后的值。

        示例：
        const (
            a = iota   // 0
            b          // 1
            c          // 2
            d = "ha"   // 独立值，iota += 1
            e          // "ha"，iota += 1
        )

        常见用法
            位运算枚举：Read = 1 << iota  // 1, 2, 4
            跳值：_ = iota 跳过 0
            自定义起始：a = iota + 1  // 1, 2, 3

运算符
    可用++，--，运算符同c++
    同样具有+=等一系列运算，以及<<=(左移后赋值)，&=(按位与后赋值)...
