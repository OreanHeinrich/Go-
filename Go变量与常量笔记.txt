Go 语言学习笔记 —— 变量与常量

一、变量部分

1. 短变量声明 :=
  - 只能用于函数体内（局部作用域），不能用于包级变量。
  - 自动类型推断，无需显式指定类型：name := "Go"
  - 包级变量必须用 var 声明。

2. 多变量声明与重新声明
  - 同时声明多个：a, b := 1, "hello"
  - 左侧至少有一个新变量时，可对已存在变量重新赋值：a, b := 2, 3
  - 全部已存在时必须用 = 赋值。

3. 作用域与遮蔽
  - 作用域为当前块 {}。
  - 内层同名变量会遮蔽外层，外层值不受影响。

4. var 与 := 对比
  - var：包级/局部均可，可只声明不赋值（零值），可指定类型。
  - := ：仅局部，必须立即赋值，类型靠推断。


二、常量部分

1. const 与 iota 原理
  - const 声明编译期不可变常量。
  - iota 是编译期计数器，每个 const 块从 0 开始，每新增一行 +1。
  - 遇到下一个 const 时重置为 0。

2. 常量值省略规则
  - 省略常量值时，默认复用上一行的表达式（含 iota）。
  - 因 iota 逐行递增，省略行会得到递增后的值。

  示例：
  const (
      Sunday = iota  // 0
      Monday         // 1（复用 iota）
      Tuesday        // 2
  )

3. 常见用法
  - 位运算枚举：Read = 1 << iota  // 1, 2, 4
  - 跳值：_ = iota 跳过 0
  - 自定义起始：a = iota + 1  // 1, 2, 3

4. 要点
  - iota 按行递增，与实际值无关，值由表达式决定。
  - 省略复用的是表达式模板，不是上一行的最终值。
  - iota 只能在 const 中使用。


小结
  := 只能用于函数体内，做局部短变量声明。
  const 中 iota 是行计数器，省略值时复用上一行表达式，实现简洁枚举。
